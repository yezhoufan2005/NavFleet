v1.0.0 的信息架构是「一个塞满的仪表盘 + 三个附属页」。下面三个候选各自代表一种取舍。线框刻意画成 灰阶细线 —— 这一轮要判断的是结构，不是配色和视觉。三张图纸之后是四个需要你拍板的问题。

盘点依据 docs/frontend-parity.md 338 条现状清单 · docs/frontend-research.md 24 项任务流与 8 条调研约束
硬约束 IA 1–3 级进主导航、4 级用 tab（Grafana）· 分区依据是「谁在什么时候要做什么」（Datadog）· 主屏收敛到 4–5 个信号（仓储机器人车队）· 大屏不可交互且无会话超时
红线 只读监控（无控制下发）· 单实例内网（无多租户）

三个候选的共同结论

不管选哪一个，有两处收敛我建议照做，因为它们与「地图放哪」无关：

  • 大屏不是一个分区，是一种模式。它必须不可交互、无会话超时，所以它是独立入口 /wall + kiosk 凭据，不进主导航。原计划的七个分区因此先减一。
  • 历史回放不是一个页面，是设备详情的一个 tab。现在它是独立页，代价是工程师查完 实时还要在历史页重新选一次设备 —— 这正是那条「6 步且拿不到答案」的排故流程的一半。

与选型无关，但要一起定

三项跨候选的设计

导航模型：左侧栏 + 细顶栏

侧栏三态（展开 / 收起 / 覆盖），顶栏只放面包屑、车队选择、会话、实时状态点。

选侧栏而非顶栏导航的理由是具体的：16:9 屏上垂直像素比水平稀缺，而地图与曲线画布 吃的正是高度。顶栏导航要占掉 56–64px 通高，侧栏收起后只占 44px 通宽。

URL：从 hash 迁到 web history

现在是 createWebHashHistory()，原因写在代码注释里：nginx 没有 try_files，前端镜像也没有自定义 conf。

迁移的收益是刚需而非美观：Phase 16D 的告警外发要「点通知直达那一条告警」，而告警中心的筛选状态 现在完全不进 URL，刷新即回默认。代价明确 —— 前端镜像加一份 nginx conf （try_files $uri /index.html）+ 边缘 location / 同步，属于部署改动。

断点：两端是平板与大屏，不是手机

现状是四个凭手感加的断点（1560 / 1320 / 1240 / 860）。改为一条刻度：

768 平板竖 · 1024 平板横 · 1280 笔记本 · 1536 桌面 · 1920 值班台 · 2560 墙面

现在的 a11y 审计只跑过 1440×900 一个视口 —— 新前端要把 1024 与 2560 也纳进 axe。

大屏值班模式 · 独立入口

它的难点在凭据与「屏幕卡住看不出来」，不在布局

墙面看板的硬规则 NavFleet 现状的冲突
不能有会话超时 15 分钟 access token + 静默刷新，而刷新是 fire-and-forget、失败时不做任何事 → 一块挂三个月的屏会在某次刷新静默失败后停住，而且看不出它停了
不可交互、无光标无菜单 需要一套专门的只读渲染路径，不能复用带侧栏的外壳
大字号、高对比、隔房间可读 自检问题：有人在两米外、两秒内能看懂什么？另外显示墙底边通常离地约 1.2m，画面下部三分之一容易被前排设备遮挡，重要内容不放最下面

结论：/wall 需要 kiosk 凭据（长期有效 + 只读 + 审计可辨识，不做匿名开放）、 画面上必须有数据新鲜度指示（最后更新时刻 + 超阈值变色），刷新失败要能自愈或显式报错。

需要你拍板

四个问题

01 · 选哪张图纸

我推 B。理由不是"总览更时髦"，而是 A 让主屏答错了问题（答"大家都在哪"而不是 "该管哪几台"），C 则把决策转移给了每一个使用者。如果你认为在我们的实际规模（示范 6 台、目标几十到 数百）下 A 仍然成立，那是一个合理的反对意见 —— 调研那条经验的前提是 40 台以上。

02 · 规模退化要不要做

6 台与 200 台的最优默认视图不同。方案：/devices 的默认视图按车辆数自动选 —— 不超过阈值 默认地图，超过则默认列表。好处是同一套 IA 在两端都不难用；代价是多一条"为什么今天变成列表了"的 解释成本。要做的话阈值定多少？我倾向 24。

03 · 迁到 web history 同意吗

它要动部署（前端镜像加 nginx conf + 边缘路由同步），所以必须现在定，不能等 Phase 14 再说。 不迁的后果是告警直达链接与筛选状态入 URL 这两项都要绕着走。

04 · 声音提醒要不要做

值班室无人时它是刚需，但浏览器自动播放策略要求先有一次用户交互才能解锁，且会带出静音、音量、 免打扰时段一串配置。做的话我会在登录后放一个一次性的"启用声音提醒"； 不做则大屏模式对无人值守场景的价值会打折。
